# Opportunity Engine - Job Search Optimization Tool

A clean, modern web app to help you optimize your job search strategy. Track opportunities, manage contacts, plan your week, and monitor progress all in one place.

## Features (STAGE 1)

- **🧠 Brain Dump**: Quick notes and ideas about your job search
- **👥 Contacts**: Manage professional connections and referral sources
- **💼 Opportunities**: Track job positions you're interested in
- **📅 Weekly Plan**: Set weekly job search goals and action items
- **📈 Progress**: Monitor job search metrics and milestones

## Design

- Clean, modern UI inspired by productivity tools like Notion
- Soft color palette (greens and purples)
- Rounded cards and smooth interactions
- Responsive sidebar navigation
- Gradient backgrounds for visual depth

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Fast build tool
- **CSS3** - Custom styling with gradients and animations

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will start at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview

```bash
npm preview
```
